# 📊 Power BI Sales & Operations Performance Dashboard

## 📌 Project Overview

An interactive Power BI dashboard developed to monitor Sales and Operations performance through key business KPIs.

The dashboard helps management track sales achievement, targets, regional performance, lead conversion and profitability.

## 🎯 Business Objectives

* Monitor actual sales against targets
* Analyze regional sales performance
* Track lead conversion performance
* Identify target gaps
* Monitor profitability and business KPIs
* Support data-driven management decisions

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Excel
* Data Modeling
* Star Schema

## 📊 Key KPIs

* Total Sales
* Sales Target
* Target Achievement %
* Target Gap
* Lead Conversion
* Regional Sales %
* Profit
* Profit Margin
